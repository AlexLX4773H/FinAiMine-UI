# FinAiMine-UI

> React frontend — Stock Dashboard, Chat Interface, Per-Stock Analysis

Part of the [Fin AI Mine](../plan.md) project.

## Tech Stack
- Vite + React 18 (TypeScript)
- TradingView Lightweight Charts / Recharts
- Vanilla CSS (dark theme, glassmorphism)
- WebSocket for streaming chat

## Getting Started
```bash
npm install
npm run dev
```
